# Purchase Pattern Analytics using Market Basket Analysis

## 📌 Project Overview
This project analyzes retail transaction data to discover products frequently purchased together using Market Basket Analysis and the Apriori algorithm.

## 🎯 Objective
Identify customer purchase patterns and generate association rules to support cross-selling and product bundling strategies.

## 🛠 Tools & Technologies
- Python (Pandas, NumPy, mlxtend)
- Apriori Algorithm
- Association Rule Mining
- Power BI
- Jupyter Notebook

## 🔄 Workflow
1. Data Cleaning & Preprocessing
2. Basket Creation
3. Transaction Encoding
4. Apriori Algorithm
5. Association Rule Mining
6. Power BI Visualization

## 📊 Key Insights
- Identified strong product associations using lift and confidence metrics
- Revealed frequent product combinations for bundling strategies
- Enabled data-driven marketing decisions
